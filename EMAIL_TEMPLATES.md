## Cómo Usar Estos Templates

### 1. Copiar y Personalizar

```bash
# Reemplaza los placeholders:
[NOMBRE] → Nombre del cliente (de PayPal)
[LICENCIA-AQUI-32-CARACTERES] → Licencia generada
[FECHA] → Fecha de vencimiento
[PAYPAL-ORDER-ID] → ID de transacción de PayPal
[XX.XX] → Monto pagado
```

### 2. Generar Licencia

```bash
# Mensual
node generate-license.js monthly

# Anual
node generate-license.js annual

# Lifetime
node generate-license.js lifetime
```

### 3. Enviar Email

Puedes usar:
- Gmail (copiar/pegar template)
- Outlook
- Servicio automatizado (SendGrid, Mailgun)

## Automatización (Opcional)

### Usando Zapier (No-code)

1. Trigger: PayPal → "New Payment"
2. Action: Gmail → "Send Email"
3. Template: Copiar template de arriba
4. Variables: Mapear datos de PayPal

### Usando Node.js

**IMPORTANTE: Este es solo un ejemplo. NO uses credenciales hardcodeadas.**

```javascript
const nodemailer = require('nodemailer');

// Usa variables de entorno para credenciales sensibles
// Crea archivo .env:
// EMAIL_USER=contacto@optimasolutions.uy
// EMAIL_PASSWORD=tu-app-password-de-gmail
// 
// Instala: npm install dotenv
// Usa: require('dotenv').config();

async function sendLicense(buyerEmail, plan, license, orderId) {
  let transporter = nodemailer.createTransporter({
    service: 'gmail',
    auth: {
      user: process.env.EMAIL_USER,     // Variable de entorno
      pass: process.env.EMAIL_PASSWORD  // Variable de entorno (App Password de Gmail)
    }
  });

  const templates = {
    monthly: `Asunto: Tu Licencia Premium...`,
    annual: `Asunto: Tu Licencia Premium Anual...`,
    lifetime: `Asunto: Tu Licencia LIFETIME...`
  };

  await transporter.sendMail({
    from: 'Instagram Pro <' + process.env.EMAIL_USER + '>',
    to: buyerEmail,
    subject: templates[plan].split('\n')[0],
    text: templates[plan]
      .replace('[LICENCIA-AQUI-32-CARACTERES]', license)
      .replace('[PAYPAL-ORDER-ID]', orderId)
  });
}

// NUNCA hagas esto en producción:
// user: 'contacto@optimasolutions.uy',  ❌ MAL
// pass: 'tu-password'                    ❌ MAL
//
// Siempre usa:
// user: process.env.EMAIL_USER,          ✅ BIEN
// pass: process.env.EMAIL_PASSWORD       ✅ BIEN
```
